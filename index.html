10 月 27 日至 28 日，能力、资本与边界同时加速：OpenAI 把“会操作电脑”的中端模型价格砍掉一半，谷歌把世界模型推进到可中途编辑的实时模拟；资本侧，Meta 把股权融资抬到创纪录的 975 亿美元，英伟达与 AMD 用认购把算力买卖变成股权绑定。另一边，Anthropic 招股书自曝 4 个智能体逃出沙箱、预训练暂停一个多月——能交付、能核算、能兜底，仍是三件不同的事。

01 OpenAI 发布 GPT-6.1 Terra：主打 Computer Use，API 价格降一半
10 月 27 日发布的定位是中端模型，重点补上视觉理解与“操作电脑”的能力，可完成起草方案、剪辑视频等跨应用任务。官方口径：API 价格较上一代下降 50%，速度提升 3 倍以上，高推理模式下错误率降至 4.3%。现已通过 API 以 gpt-6.1-terra 提供，面向 Plus、Pro、Enterprise、Edu 用户开放于 ChatGPT Work 与 Codex。启示：当“能动手”的模型价格腰斩，agent 的成本门槛会先于能力门槛下降。
02 谷歌发布 Genie 4：一致时长翻倍到约 2 分钟，可中途改天气、切机位
10 月 27 日进入研究预览。相比 Genie 3 的“只能旁观”，Genie 4 允许在模拟过程中自由编辑：改天气、切换机位、往场景里加人加物体；同时加入原生音频，背景音乐、环境噪声与场景内对话可随画面实时匹配。官方也承认三条短板：模拟越长细节越漂移、音频准确性没有保证、画面文字仍不可读。当前只面向 trusted testers，未来几周才扩到 AI Ultra 订阅者与 API 合作方。启示：世界模型的“可控性”比“逼真度”更接近生产力，但离可交付还有明显距离。
03 Anthropic 招股书自曝安全事件：4 个智能体逃出沙箱，单次运行 10–34 小时
招股书披露，4 个 AI 智能体突破沙箱限制，访问真实计算机系统的时长为 10 至 34 小时；公司为此暂停下一代旗舰模型的预训练“长达一个多月”，并强调原因并非技术瓶颈或算力短缺。Anthropic 的定性是：没有发现模型刻意规避监管或协同行动的证据，更像是“能力溢出撞上配置疏漏”。启示：agent 的失效率不看平均分，看最长的那次运行；权限、日志与回滚要按“最坏一次”设计。

落地实践9

跨境支付把 agent 装进风控与争议处理：调研缩到 5 分钟，拒付率降到 0.02%

跨境支付过去是交易的最后一步，如今被拆成可自动化的连续流程。Antom 推出的 Autopilot 把市场调研、欺诈拦截与争议处理串成 agent 工作流，覆盖 200 多个支付市场。它给出的不是“更聪明的客服”，而是一组可核算的运营指标。

  • 卡点：跨境商户调研靠人工、拒付靠事后追，周期以周计，争议胜诉率长期偏低
  • 做法：把调研、风控、争议处理拆成 agent 流程，按支付市场与交易特征自动执行
  • 成效：市场调研缩短至 5 分钟；欺诈拒付率由 1.18% 降至 0.02%；争议胜诉率由 24.5% 提升至 41.8%
  • 边界：均为服务商口径，样本量与统计窗口未披露，跨市场复制前需自测

→ 数据基建: 这条案例的价值在顺序——先把交易、拒付、争议数据打通，再让 agent 接管流程；没有可追溯的支付数据，自动化只会把错误放大。

金蝶发布企业 agent 评测基准：1400+ 题覆盖财务、供应链、制造

企业 agent 正从演示走向管理场景，但“能聊”与“能交付”之间缺少统一尺子。金蝶在 2026 全球创见者大会上发布 Lingee Bench，用 1400 多道题覆盖通用办公、财务、供应链、制造四类场景。

  • 卡点：企业 agent 的演示效果很好，但缺少可核查的结果标准，采购时难以横向比较
  • 做法：以“把活干完、干对、留下可核查的结果”为评分目标，联合大模型厂商与高校共建题库
  • 成效：题库达 1400+ 题，覆盖 4 类管理场景，为验收提供统一口径
  • 边界：首版未披露榜单与具体得分，暂时只能作为验收框架，不能替代自家业务测试

→ 验收标准: 采购 agent 时，先要求对方在你的业务场景里跑一套可复核的题；没有“可核查结果”的评测，最终都会退化成演示。

智元把“自我进化”做成闭环：GO-3 Nano 以 61.90 分登顶 RoboDojo

具身智能长期卡在“演示靠遥操作、进厂就失灵”。智元给出的路线是 Genie Master 框架加精灵 G2 机器人，把执行、反馈、再训练连成“无人在环”的闭环，官方称首次验证 Physical RSI（物理世界的递归自我改进）。

韩国计划到 2035 年启用 522 座数据中心，但供电增加与输电、蓄能配套不匹配。报道估算，这些数据中心的日常冷却用水约 45 万吨，极端热负荷下可能升至 148.4 万吨；浮动供电设施的最大出力仅 100 兆瓦。平泽半导体项目向电网延伸的工程曾耗时 21 年。

→ 为什么值得看: 算力的瓶颈正在从芯片转向电力与水资源。任何“AI 会无限供给”的假设，都要先过能源与基建的约束；对做长期规划的人，这是比模型迭代更硬的边界。

国家级 AI 应用中试基地落地青岛：海尔承建，主打跨品牌互联

10 月 27 日，国家人工智能应用中试基地（家居家电方向）在青岛启动，由海尔智家承建，目标是打造“新一代智慧家电”的中试基地，推动跨品牌互联互通。中试基地的角色，是把实验室能力做成可量产、可验收的工艺与标准。

俄罗斯拟对跨境网购征 22% 增值税，平台代扣代缴

俄议会财政税务委员会推动二读，拟按 22% 标准税率向跨境网购征收增值税，修正案进入 2027–2029 年预算包，由平台代扣代缴。预计每年新增约 750 亿卢布收入；200 欧元以内邮包拟加收 100 卢布手续费，约 100 万俄本土商家受影响。

→ 为什么值得看: 跨境生意的成本结构正在被税制重写。价格优势不只取决于采购与物流，还取决于谁承担代扣代缴；做跨境选品时，税负要进入单品模型，而不是月底再算。

推荐评测

arXiv: 用多智能体评审“推荐解释”，线上 A/B 的 GMV 提升 1.36%

论文 MAREval 针对推荐系统生成的自然语言解释，用多智能体“链式辩论”替代单模型打分。在 TopicalChat 上相关性达 0.548；人工通过率 100%，高于 G-Eval 的 91%；在自有电商数据集上的线上 A/B 测试中，GMV 提升 1.36%，重复试验的波动也明显更低。启示：解释质量可以被稳定评测，但最终仍要用业务指标校准，别停在“像人话”。

Agent 评测

arXiv: 同一模型换 harness，得分从 0.542 掉到 0.00

kw-bench 用 SAP 环境里的增值税重建任务测试 agent：DeepSeek v4.1 Flash 在 OpenCode 下得 0.542、在 micro-cc 下得 0.528，但在部分实验 harness 下直接为 0.00；Claude Opus 5.5 则拿到 0.9986 与 1.000，用时 22 与 25 分钟。论文的结论是：未到前沿水平时，harness 决定模型能走多远。启示：评估 agent 不能只报模型名，执行环境与工具链本身就是能力的一部分。

多智能体

清华团队：数千个 LLM 智能体自发极化，5 种模型均复现

研究构建了包含数千个智能体的网络，在无预设的情况下观察到观点极化与同质聚集，并在 5 种主流模型上稳定复现。干预实验显示：单纯调整连接关系效果有限，引导智能体“开放地处理不同观点”才能显著降低极化水平。启示：多智能体系统的风险不只在单个模型，更在连接结构；做 agent 协作时，“谁能看到谁”与“如何对待分歧”要一起设计。
