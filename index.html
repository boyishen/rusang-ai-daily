01 OpenAI 融资规模缩水：首期 110 亿美元到账，估值 1.25 万亿
据财联社报道，OpenAI 已完成 110 亿美元首期款项，投前估值 1.25 万亿美元；整轮规模较最初规划的 3000 亿美元大幅缩减至约 200 亿美元，原估值预期为 1.4 万亿美元。启示：头部模型公司的估值锚，正在从叙事回到现金流；与其合作的账期、条款，会比去年更硬。
02 微软逐步终止甲骨文算力租约：旧芯片的算力不再续，涉及年化 超 40 亿美元产能
报道称微软正逐步终止与甲骨文的 AI 算力租约，原因指向较旧的英伟达芯片；同期 IREN 的相关交付从年底推迟到明年 1—2 月，涉及年化超 40 亿美元的收入产能。启示：算力不是越多越好，而是越新越值钱；租算力的一方，要把“代际折旧”写进合同。
03 Anthropic 让智能体先“做梦”：Opus 5.5 任务得分 0.655 → 0.838
Anthropic 研究让 Claude 智能体在任务间隙做离线复盘，把失败轨迹重新消化后再执行；长周期任务得分从 0.655 提升到 0.838，企业文档测试达标率从 13% 升到 48%，配合检索工具后综合得分升至 61%。启示：Agent 的进步不一定靠更大的模型，也可以靠“事后复盘”这一层工程。

案例报告9

Anthropic 内部 RSI：Claude 已主导 26% 研发，实验时间缩短 80%

Anthropic 内部三个模型（Model 2/3/4）曝光：Model 4 在 AECI 拿 178.6 分，超 Opus 5.5 约 3.9 分，相当于领先三个月。同期披露，Claude 已主导 26% 的研发工作，递归自我改进把实验时间压缩约 80%。

  • 卡点：模型迭代靠人堆实验，一轮训练以月计，方向试错的成本高得离谱
  • 做法：把“提假设—跑实验—读结果”的重复环节交给模型闭环，人只保留选题与验收
  • 成效：Model 4 得分 178.6、领先 Opus 5.5 约 3.9 分；研发 26% 由 Claude 主导；实验时间缩短 80%
  • 边界：26% 是“参与度”不是“替代率”，评测口径与人工复核仍是真正的瓶颈

→ 效率账本: 真正省下来的不是人头，是“从想法到验证”的周期；周期缩 80%，同样的团队一年能试的方向就多出数倍。

数据基建8

PPIO：给每个 Personal Agent 配一台“云电脑”，冷启动 200 毫秒

PPIO 把“云电脑”做成面向 Agent 的沙箱 API：按需拉起、用完销毁，权限与网络在沙箱里收口。官方数据冷启动 200 毫秒以内，2.5 万并发下成功率 99.8%，相关业务增长超过 120 倍。

  • 卡点：Agent 要操作浏览器、文件与软件，本地跑不安全、不可审计，云端跑又太慢
  • 做法：把桌面环境封装成 API，冷启动压到毫秒级，环境用完即销毁，减少状态污染
  • 成效：冷启动 <200ms；2.5 万并发成功率 99.8%；业务增长 120 倍以上
  • 边界：延迟与并发达标，不等于任务成功率；长任务的状态恢复与断点续跑仍难

→ 数据基建: Agent 的竞争正从“模型多聪明”下沉到“环境多稳定”；谁掌握沙箱、权限与操作回放，谁就拿到 Agent 的运维入口。

→ 避坑清单: 任何靠“用户生产内容 + 搜索分发”的生意，都要先想清楚：当答案可以直接生成，你还剩下哪块不可替代？
